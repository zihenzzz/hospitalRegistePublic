## 🚀 解决方案

### 方案1：手动开启服务端口（推荐）

#### 步骤：
1. **打开微信开发者工具**
   - 如果已经打开，直接使用
   - 如果没有打开，手动打开微信开发者工具

2. **开启服务端口**
   - 点击顶部菜单：**设置** → **安全设置**
   - 找到 **"服务端口"** 选项
   - 勾选 **"开启服务端口"**
   - 点击 **"确定"** 保存

3. **重新运行项目**
   - 在 HBuilderX 中点击 **运行** → **运行到小程序模拟器** → **微信开发者工具**
   - 或者直接使用已打开的微信开发者工具

#### 图示：
```
微信开发者工具
  └─ 设置 (Settings)
      └─ 安全设置 (Security Settings)
          └─ ☑ 开启服务端口 (Enable Service Port)
```

---

### 方案2：手动导入项目（最简单）

如果不想配置服务端口，可以手动导入项目：

#### 步骤：
1. **打开微信开发者工具**
   - 启动微信开发者工具

2. **导入项目**
   - 点击 **"+"** 或 **"导入项目"**
   - 选择项目目录：`D:\github-project\hospitalRegistePublic\hospital-registration-wx`
   - 选择 **AppID**：可以选择 **"测试号"** 或填写自己的 AppID
   - 点击 **"导入"**

3. **查看效果**
   - 项目会自动编译并显示在模拟器中

---

### 方案3：使用命令行启动（高级）

## 💡 常见问题

### Q1: 为什么 HBuilderX 无法自动打开微信开发者工具？
**A**: 需要开启微信开发者工具的服务端口（设置 → 安全设置 → 开启服务端口）

### Q2: 编译成功但看不到页面？
**A**: 
1. 手动打开微信开发者工具
2. 导入项目目录
3. 查看控制台错误信息

### Q3: 如何查看小程序运行日志？
**A**: 在微信开发者工具中：
- 点击 **"调试器"** 标签
- 查看 **Console** 面板
- 查看 **Network** 面板（网络请求）

### Q4: 页面显示空白？
**A**: 
1. 检查控制台是否有错误
2. 检查 API 地址配置（`config/app.js`）
3. 检查后端是否启动
